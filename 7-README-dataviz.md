# Data Visualization: Global Development Story

**Skill:** Data visualization with Matplotlib, Seaborn and Plotly.

Tells the story of life expectancy and wealth since 1952 with histograms, small multiples, a heatmap, an animated bubble chart, a world map, a range-slider time series and a good-vs-bad chart design comparison. All data is bundled with Plotly, so no downloads are needed.

## Run
1. Open Google Colab, choose File, then Upload notebook, and pick `7-dataviz_global_development.ipynb`.
2. Runtime, then Run all.
